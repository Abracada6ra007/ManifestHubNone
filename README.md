## 下载步骤 / Download steps

### 1.找到对应游戏的APP ID / Find the corresponding game's APP ID
*   SteamDB: https://steamdb.info/
### 2.复制APP ID / Copy the APP ID
*   粘贴到分支搜索栏里，回车 / Paste it into the branch search bar and press Enter
*   搜索不到就是没有该游戏的资源 / If you can't find it, it means there are no resources for that game
### 3.下载压缩包文件 / Download the zip file
*   点击打开你在第二步找到的分支，点击Code，下载压缩包
*   Click on the branch you found in the second step, click on "Code", and download the zip file
